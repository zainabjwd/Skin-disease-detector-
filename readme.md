# Skin Disease Detection AI

An AI-powered skin disease detection system that uses **Deep Learning and Computer Vision** to classify skin lesion images into different disease categories. The project uses **EfficientNetB0** with the **HAM10000 dataset** to develop an automated image-based classification system.

## Features

* Deep learning-based skin lesion classification
* Image preprocessing and augmentation
* EfficientNetB0-based classification model
* Model evaluation using accuracy, loss, precision, recall and F1-score
* Class-weighted training to handle dataset imbalance
* Expandable dataset for improved disease coverage
* AI Agent integration currently in progress

## Dataset

The project currently uses the **HAM10000 (Human Against Machine with 10,000 training images)** dataset, containing dermatoscopic images of skin lesions across multiple diagnostic categories.

Dataset: [HAM10000 Dataset](https://www.kaggle.com/datasets/kmader/skin-cancer-mnist-ham10000)

## Model

The project uses **EfficientNetB0**, a convolutional neural network architecture that provides a balance between computational efficiency and classification performance.

The model is configured for multi-class skin lesion classification and uses transfer learning.

### Model Pipeline

```text
Input Skin Image
       ↓
Image Preprocessing
       ↓
Data Augmentation
       ↓
EfficientNetB0
       ↓
Feature Extraction
       ↓
Classification Layer
       ↓
Predicted Skin Disease
```

## Model Evaluation

The model is evaluated using:

* Accuracy
* Loss
* Precision
* Recall
* F1-Score
* Confusion Matrix
* Classification Report

The model is being continuously improved through experiments with preprocessing, class balancing, transfer learning and training strategies.

## How to Run

After downloading or cloning the repository:

### 1. Open the project folder

```bash
cd skin-disease-detector
```

### 2. Create and activate a virtual environment

For Windows:

```bash
python -m venv venv
.\venv\Scripts\activate
```

### 3. Install the required dependencies

```bash
pip install -r requirements.txt
```

### 4. Add the dataset

Download the required dataset and place it in the `data/` folder. The dataset is not included in this repository due to its size.

### 5. Run the application

```bash
streamlit run app/streamlit_app.py
```

The application will open automatically in your browser. If it does not, open the local URL shown in the terminal, usually:

```text
```

### 6. Use the application

Upload a skin lesion image and the application will process it and display the predicted result.
